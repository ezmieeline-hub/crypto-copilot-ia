# Crypto Copilot IA

Application privée et responsive pour iPhone, iPad et navigateur.

## Déjà intégré
- Connexion privée
- Données Binance
- EMA 9/20/50/100/200, SMA 200, RSI, MACD, ATR, ADX, volume
- HH / HL / LH / LL
- Supports et résistances
- Bougie de confirmation clôturée
- Score de confluence
- Entrée, stop, TP1, TP2, TP3
- Import de capture TradingView avec OpenAI
- Surveillance automatique et notifications Telegram
- Journal SQLite

## Déploiement Render
1. Importer le contenu du ZIP dans le dépôt GitHub privé.
2. Dans Render, créer un Blueprint depuis le dépôt.
3. Renseigner APP_USERNAME, APP_PASSWORD et les clés facultatives.
4. Déployer.

Pour les captures : OPENAI_API_KEY. Pour les alertes iPhone : TELEGRAM_BOT_TOKEN et TELEGRAM_CHAT_ID.

## Prudence
Outil d'aide à l'analyse uniquement. Aucun gain n'est garanti. Les niveaux doivent être vérifiés avant toute décision.

## Prochaine validation
